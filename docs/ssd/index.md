# SSD

This section of the guide will explain the "SSD" rotation which will get you from lvl 1 to lvl 100 and enough cash to afford your next infamy (~125m).

## SSD Versions

### No Booster, No Gamepass

This version does not need you to own any gamepasses or use any boosters and is structured as follows:

- Diamond Store Sweep x2
- Art Gallery x4
- Sweepot x5
- Shadow Raid x5

### Booster/Gamepass

This version requires you to either own the "Double Cash" gamepass OR to use a +100% cash booster which can be bought with chips. This version is commonly referred to as "SSD Booster".This version is structured as follows:

- Diamond Store x2
- Art Gallery x2
- Sweepot x4
- Shadow Raid x4
- Nightclub Sweep x1
- Nightclub Minimum x1

### Gamepass and Booster

This version requires you to own the "Double Cash", "Double XP", "Cheaper Infamy" gamepasses and requires you to use a +100% cash booster and a +100% xp booster. This version is structured as follows:

- Diamond Store x2*
- Nightclub Minimum x3
- Sweepot x3
- *By the end of this rotation, your repeat bonus will not replenish enough to reach lvl 100 on any repeats of the rotation. To fix this you can add an extra Diamond Store on any repeats of this rotation.
