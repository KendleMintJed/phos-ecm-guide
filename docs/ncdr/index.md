# NCDR

This section of the guide will explain the “NCDR” rotation which will get you from lvl 1 to lvl 100 in the shortest time possible.

## NCDR Versions

### No Booster, No Gamepass

This version does not require you to own any gamepasses or use any boosters and is structured as follows:

- Depot x4
- Nightclub x4
- Rush Hour x3

### Booster/Gamepass

This version requires you to either own the “Double XP” gamepass OR use a +100% xp booster which can be bought with chips. This version is commonly referred to as “NCDR Booster”. This version is structured as follows:

- Depot x3
- Nightclub x3
- Rush Hour x2

### Booster and Gamepass

This version requires you to both own the “Double XP” gamepass and use a +100% booster which can be bought with chips. This version is structured as follows:

- Depot x3
- Nightclub x4*
- *By the end of this rotation, your repeat bonus will not replenish enough to reach lvl 100 on any repeats of the rotation. To fix this you can add an extra Nightclub on any repeats of this rotation.
