# Depot

Depot is featured on all 3 versions of NCDR

!!! ecm
    at 32s on the timer

![](media/depot/summary.png)

1. Kill the spawn guard, grab their key, loot spawn cola if it is there.

2. Run and loot the furthest 3-garage door.

    !!! callout
        If you get more than one bag, give a quick chat

3. Move and secure all your bags to the escape.
